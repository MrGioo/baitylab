Abre el panel de XAMPP del computador de la sala e inicia Apache y MySQL.
Entra a http://localhost/phpmyadmin/.
Crea una base de datos vacía llamada baitydb, utf8mb4_general_ci.

Descomprime tu proyecto, haz clic derecho en la carpeta y abre la terminal (o ábrela en VS Code).
Crea el entorno virtual usando el Python estable del laboratorio:
python -m venv .venv (copiar y pegar)
Actívalo:
.\.venv\Scripts\activate (Copiar y pegar)
Si falla activando por politicas usa:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned 

pip install -r requirements.txt (copiar y pegar)

python manage.py makemigrations / Usar
python manage.py migrate / Usar

python manage.py createsuperuser / Usar baity baity@gmail.com 1234

python manage.py runserver / Usar
